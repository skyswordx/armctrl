# daemon

## 这个目录做什么

这里放应用服务层。
当前核心是 `executor.py`，
负责把“请求对象 -> 安全校验 -> 适配器执行 -> 统一响应”串成完整链路。

## 主要组件

- `executor.py`：命令执行器，处理 health、state、move、teleop、debug profile、cancel。

## 实现思路

`ArmCommandExecutor` 不关心底层是 fake 还是真 SDK。
它只关心两件事：

1. 这个请求安不安全；
2. 这个请求该调用 adapter 的哪个统一方法。

teleop 的“目标积分”也放在这里，
因为它属于业务执行语义，不属于手柄映射层。

当前 teleop 还有一个明确的安全语义：

1. 从任何非 `teleop` 模式恢复接管时，第一拍先读取当前实测末端/夹爪状态；
2. 把这组实测值写成新的 teleop 基线，并发送一条“保持当前状态”的命令；
3. 从第二拍开始，摇杆增量才真正累加到这个基线上。

这样 `executor` 内部积分目标、adapter 内部控制目标和机械臂实测姿态会先重新对齐，
避免模式切换瞬间把旧目标重新发给控制器。
