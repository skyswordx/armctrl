# armctrl

本目录存放 `armctrl` 独立机械臂控制仓库的过程文档、架构决策记录与外部参考项目调研记录。

## 当前文档

- `subsystem/arm_control_subsystem_blueprint.md`：机械臂控制子模块总 Wiki，覆盖分层、生命周期、CLI、daemon、SDK 复用规则、Xbox 调试入口、debug profile 和分阶段执行计划
- `reference_projects_and_sjtu_roboclaw_notes.md`：参考项目调研记录，包含 LeRobot、ARX5 LeRobot 插件、SJTU RoboClaw、FrankaPy、Polymetis、TidyBot2、MoveIt Servo，以及 bringup 阶段的官方 SDK 与参考仓管理策略
